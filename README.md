# 40K 데이터시트 번역 도우미

NewRecruit에서 복사한 편성표 텍스트를 붙여넣으면 `FACTION KEYWORD`를 읽어 BSData의 11판 진영 카탈로그를 불러옵니다. 전투 보조에서는 CP 추적과 11판 공개 스트라타젬 데이터를 함께 제공합니다.

## 실행

`index.html`을 브라우저에서 엽니다. 예시 편성표는 자동으로 채워지고 공개 데이터 연결을 시작합니다. 원격 데이터 연결에는 인터넷이 필요합니다.

## 현재 구현된 범위

- NewRecruit 텍스트와 공식 앱의 한국어/영어 roster 내보내기에서 팩션·편제·미션·전장 규모·포인트·유닛 항목을 추출합니다. 공식 앱 형식은 모델 수가 유닛 제목에 없을 때 편성 모델 행에서 수를 추정하고, 사본 타이틀과 Incursion 같은 게임 규모 줄은 유닛으로 세지 않습니다.
- BSData 공개 저장소의 11판 진영 카탈로그만 사용합니다. 스페이스 마린 챕터 등 여러 카탈로그를 연결할 때 교차 참조를 해석합니다. 카드에 데이터 판본을 표시합니다. 로스터에 영문 진영명이 없어도 대표적인 한국어 진영명은 인식합니다.
- 사용자 제공 40K 번역 이슈 시트에서 이슈 표시와 비고가 없는 번역 357개를 보조 용어집으로 적용합니다. 명시적으로 지적된 항목은 임의로 덮어쓰지 않으며, 앱 내 용어집과 Google Sheets 승인 번역이 우선합니다.
- 원본 항목에서 프로필과 키워드를 표시합니다.
- 입력란은 붙여넣은 내용에 맞춰 높이가 늘어나고, 분대원별 편성 장비도 목록으로 보여줍니다. 로스터에 적힌 인핸스먼트는 선택 편제 공개 자료와 연결해 설명을 표시하고, 인식 가능한 유닛·근접 무기 수치 보너스는 기본값과 변경값을 함께 보여줍니다.
- 유닛 행을 눌러 데이터시트 상세 내용을 접고 펼칠 수 있습니다.
- 주요 능력은 한국어와 영문을 함께 표시합니다. 확인된 능력 설명은 한국어로 표시하고, 아직 번역을 확인하지 않은 문장은 영어 원문을 유지합니다.
- 원거리·근접 무기 이름은 한국어 발음과 영어명을 함께 보여줍니다. 무기 특수 규칙은 누르면 간단 설명 토스트가 뜹니다.
- 데이터시트의 키워드와 관련 규칙 이름도 눌러 설명 토스트를 열 수 있습니다. Close-Quarters 설명을 추가했습니다.
- 유닛 카드 머리글의 −/+ 버튼으로 운드를 추적합니다. 기본값은 편성 수와 모델의 운드 능력치를 곱한 전체 운드이며, 상세 내용을 접어도 버튼은 계속 보입니다.
- 접힌 유닛 카드에도 이동·내구·방어·운드 등 기본 능력치를 요약해 표시합니다. 프로필 표의 모델/무기 이름은 무기명 번역과 같은 발음 표기를 사용합니다.
- Anti-Infantry, Anti-Monster 등 수치가 붙는 키워드는 규칙 설명을 숫자에 맞춰 표시합니다. 등록된 관련 규칙 설명도 눌러 확인할 수 있습니다.
- 키워드는 공통 규칙 패턴(예: Anti-X, Feel No Pain X+)과 BSData 프로필 설명 색인을 함께 사용합니다. 번역 사전에 없는 규칙도 BSData 원문 설명을 팝업에서 확인할 수 있고, 사전에는 한국어 명칭과 영문명을 병기합니다.
- BSData의 `sharedRules` 직접 설명과 `infoLink` 대상 ID/이름 수정자도 읽습니다. 예전처럼 프로필 텍스트에만 있던 키워드 설명 누락을 줄입니다.
- 전투 보조 페이지에서 배치, 지휘, 이동, 사격, 돌격, 타격, 전투 충격, 피격·운드 처리, 목표·종료 및 추가 확인 탭을 항상 표시합니다. 체크 항목이 있는 첫 단계가 처음 열립니다.
- 편성 단계의 Leader/Support 합류 안내와 본문이 비어 있는 능력은 전투 체크리스트에서 제외합니다. Combat Doctrines·Templar Vows처럼 군대에 공통 적용되는 선택 규칙은 한 항목으로 묶습니다.
- 전투 보조 페이지에서는 입력창, 데이터 연결 상태, 데이터시트 목록을 숨겨 체크리스트에 집중합니다. `Anti-X Y+`는 Infantry 등 일부 이름만 하드코딩하지 않고 대상 키워드를 일반 패턴으로 읽습니다.
- 전투 보조의 미션·배치·양측 전술과 5개 라운드의 양측 점수를 기록하고 합계를 표시합니다. 기록은 이 브라우저에 저장되며 새 게임 버튼으로 초기화할 수 있습니다.
- 전투 보조 상단에서 CP를 증감할 수 있습니다. 스트라타젬은 접이식 보관함에 모아 사용 가능한 단계별로 확인합니다. CP 사용 상태는 브라우저에 저장됩니다. 공통 스트라타젬은 공개 카드 데이터에서, 선택 편제 전용 스트라타젬과 편제 능력은 Game Datacards 공개 11판 자료에서 편성표의 진영·편제에 맞춰 불러옵니다.
- 디테치먼트 능력은 전투 보조의 접이식 `선택 편제 능력` 영역에 한국어 설명과 영문 원문을 표시합니다. 선택 편제와 일치하는 공개 자료가 없으면 해당 상태를 안내합니다.
- 매칭되지 않은 유닛과 모호한 후보를 따로 표시합니다.
- 매칭 사전 가져오기/내보내기는 제거했습니다. 예외적으로 데이터시트를 직접 선택한 연결은 현재 브라우저 세션 안에서만 적용합니다.
- 분석 후 Wikimedia Commons에서 대표 이미지를 자동 조회해 표시합니다. 검색 결과가 없거나 허용된 라이선스 이미지를 찾지 못하면 이미지가 표시되지 않을 수 있습니다. 이미지 출처와 저작자 정보는 상세에 함께 표시하고, 이미지는 이 브라우저에 저장해 다음부터 접힌 유닛 제목 옆에도 보여줍니다.
- 선택형 크루세이드 능력은 일반 데이터시트에 섞여 표시되지 않도록 제외합니다.

## V2 비교 프로토타입

현재 `codex/google-sheets-ai-translation-v2` 브랜치는 V1 기능을 기준으로 Google Sheets에서 BSData 변경분을 감지하고 Gemini 번역 초안을 관리하는 파이프라인을 추가합니다. 설치·시트 구성·검수·앱 연결 방법은 [`google-sheets-v2/README.md`](google-sheets-v2/README.md)를 참고하세요. V1 기준 커밋은 `5632063`입니다.

## 다음 단계

지원되는 진영은 11판 카탈로그만 사용합니다. BSData에 등록되지 않은 유닛이나 명칭이 크게 다른 항목은 수동 연결이 필요할 수 있습니다. 한글 로스터 이름은 일부 알려진 음역 별칭을 통해 영어 데이터시트에 연결합니다. 모든 진영의 완성된 한국어 번역이 앱에 미리 포함된 것은 아닙니다. V2 번역 피드에서 승인된 항목만 적용되고, 나머지는 원문 또는 용어 사전 결과로 남습니다. 번역을 넓히려면 [`google-sheets-v2/README.md`](google-sheets-v2/README.md)의 시트 동기화와 검수 절차를 사용하세요. BSData에 아직 등록되지 않은 카탈로그와 판본별 세부 규칙은 별도 데이터가 필요합니다. 편성표 입력은 복사한 텍스트를 사용합니다.
