# 40K 데이터시트 번역 도우미

NewRecruit에서 복사한 편성표 텍스트를 붙여넣으면 `FACTION KEYWORD`를 읽어 BSData의 공개 11판 해당 진영 카탈로그를 불러옵니다. 전투 보조에서는 CP 추적과 선택 판본의 공개 스트라타젬 데이터를 함께 제공합니다.

## 실행

`index.html`을 브라우저에서 엽니다. 예시 편성표는 자동으로 채워지고 공개 데이터 연결을 시작합니다. 원격 데이터 연결에는 인터넷이 필요합니다.

## 현재 구현된 범위

- NewRecruit 텍스트와 공식 앱의 한국어/영어 roster 내보내기에서 팩션·편제·미션·전장 규모·포인트·유닛 항목을 추출합니다. 공식 앱 형식은 모델 수가 유닛 제목에 없을 때 편성 모델 행에서 수를 추정하고, 사본 타이틀과 Incursion 같은 게임 규모 줄은 유닛으로 세지 않습니다.
- BSData 공개 저장소의 주요 11판 진영 카탈로그를 로스터 진영에 맞춰 선택하며, 스페이스 마린 챕터는 공용 카탈로그와 챕터 카탈로그를 함께 연결합니다.
- 원본 항목에서 프로필과 키워드를 표시합니다.
- 입력란은 붙여넣은 내용에 맞춰 높이가 늘어나고, 분대원별 편성 장비도 목록으로 보여줍니다.
- 유닛 행을 눌러 데이터시트 상세 내용을 접고 펼칠 수 있습니다.
- 주요 능력은 한국어와 영문을 함께 표시합니다. 확인된 능력 설명은 한국어로 표시하고, 아직 번역을 확인하지 않은 문장은 영어 원문을 유지합니다.
- 원거리·근접 무기 이름은 한국어 발음과 영어명을 함께 보여줍니다. 무기 특수 규칙은 누르면 간단 설명 토스트가 뜹니다.
- 데이터시트의 키워드와 관련 규칙 이름도 눌러 설명 토스트를 열 수 있습니다. Close-Quarters 설명을 추가했습니다.
- 유닛 카드 머리글의 −/+ 버튼으로 운드를 추적합니다. 기본값은 편성 수와 모델의 운드 능력치를 곱한 전체 운드이며, 상세 내용을 접어도 버튼은 계속 보입니다.
- 접힌 유닛 카드에도 이동·내구·방어·운드 등 기본 능력치를 요약해 표시합니다. 프로필 표의 모델/무기 이름은 무기명 번역과 같은 발음 표기를 사용합니다.
- Anti-Infantry, Anti-Monster 등 수치가 붙는 키워드는 규칙 설명을 숫자에 맞춰 표시합니다. 등록된 관련 규칙 설명도 눌러 확인할 수 있습니다.
- 키워드는 공통 규칙 패턴(예: Anti-X, Feel No Pain X+)과 BSData 프로필 설명 색인을 함께 사용합니다. 번역 사전에 없는 규칙도 BSData 원문 설명을 팝업에서 확인할 수 있고, 사전에는 한국어 명칭과 영문명을 병기합니다.
- BSData의 `sharedRules` 직접 설명과 `infoLink` 대상 ID/이름 수정자도 읽습니다. 예전처럼 프로필 텍스트에만 있던 키워드 설명 누락을 줄입니다.
- 로스터의 1중대 특임대/Extremis-level Threat 효과를 요약 표시하고, 표적 및 사용 시점은 게임 중 선택 사항으로 구분합니다. 로스터 편제와 현재 데이터 판본이 다른 경우 경고합니다.
- 전투 보조 페이지에서 배치, 지휘, 이동, 사격, 돌격, 타격, 전투 충격, 피격·운드 처리, 목표·종료 및 추가 확인 탭을 항상 표시합니다. 체크 항목이 있는 첫 단계가 처음 열립니다.
- 전투 보조 페이지에서는 입력창, 데이터 연결 상태, 데이터시트 목록을 숨겨 체크리스트에 집중합니다. `Anti-X Y+`는 Infantry 등 일부 이름만 하드코딩하지 않고 대상 키워드를 일반 패턴으로 읽습니다.
- 전투 보조 상단에서 CP를 증감할 수 있습니다. 스트라타젬은 접이식 보관함에 따로 모아두고, 사용 가능한 단계별 그룹 안에서 확인합니다. CP 사용을 누르면 차감 및 완료 상태를 저장하고, 여러 단계 그룹에 표시된 같은 스트라타젬도 완료 상태를 공유합니다. 공개 카드 데이터의 10판/11판 선택과 로스터 진영·편제 일치 항목 필터를 지원합니다.
- 공개 스트라타젬 데이터는 Wahapedia 데이터 내보내기를 사용하는 커뮤니티 프로젝트에서 가져오며, 영어 원문과 출처 판본을 표시합니다. 자료에 포함되지 않은 항목은 만들어 표시하지 않습니다.
- 매칭되지 않은 유닛과 모호한 후보를 따로 표시합니다.
- 선택형 크루세이드 능력은 일반 데이터시트에 섞여 표시되지 않도록 제외합니다.

## 다음 단계

현재 번역은 브라우저 안의 용어 사전과 검증된 규칙 문구를 대입하는 방식입니다. 사전에 없는 문장은 원문이 남거나 일부 용어만 바뀌므로 자연스러운 전체 문장 번역에는 한계가 있습니다. AI 번역을 추가하려면 API 키를 브라우저에 노출하지 않는 작은 서버/프록시와 번역 결과 캐시가 필요하며, 게임 규칙 번역은 판본 확인과 사람 검수가 필요합니다. BSData 카탈로그에 없는 진영이나 세부 판본별 규칙은 별도 데이터 연결이 필요합니다. 편성표 입력은 복사한 텍스트만 사용합니다.
